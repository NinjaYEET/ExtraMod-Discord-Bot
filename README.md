**Bot Commands** :
Here is a simple tutorial for the bot.
# Setup :
/setup-ticket > Create a ticket panel in this channel
/setup-verification > Create the verification system
/setmemberrole @role > Set the verified member role
/setuplogs > Set this channel as the logs channel
# Tickets :
/ticket close > Close the current ticket
/ticket add @member > Add someone to a ticket
/ticket remove @member — Remove someone from a ticket
/ticket rename name > Rename a ticket
# Moderation :
/warn @member reason > Warn a member
/warnings @member > View warnings
/clearwarnings @member > Clear warnings
/timeout @member minutes reason > Timeout a member
/untimeout @member > Remove a timeout
/kick @member reason > Kick a member
/ban @member reason > Ban a member
/unban user_id reason > Unban a user
/purge amount > Delete messages
/lock > Lock the channel
/unlock > Unlock the channel
/slowmode seconds > Set slowmode
# Information :
/userinfo @member > View member information
/serverinfo > View server information
/help > Show this tutorial
